# Domino Test Pieces

Make a full-thickness labeled pair for every joint family, using the production cutter, plunge, fence height, reference face, and mortise-width strategy. Mark cutter size, date, joint ID, and operator. The clean factory tenon must seat by controlled hand pressure, close the shoulder without a clamp, and leave faces within 0.010 inch flush. A test mortise that intersects a groove, exposes the face, merges with another mortise, or requires hammering fails. Correct the setup and make a new test pair.
